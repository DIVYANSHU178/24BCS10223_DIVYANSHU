Nova Financial: Investment Analytics Dashboard
Problem Statement
You are building an Investment Analytics Dashboard for a portfolio management application. The dashboard fetches portfolio holding records, allows users to search and filter assets, and provides a currency display preference.
The application should use React hooks to manage state, side effects, and optimized financial calculations.

Task
Implement the solution inside the provided App.jsx file.
1. Data Fetching & Side Effects — useEffect
On component mount, simulate fetching portfolio data using setTimeout.
After exactly 600ms, populate the assets state with the provided MOCK_ASSETS array.
Set loading to false.
Create a second useEffect that updates the browser title to:
Portfolio - Total: ${formattedTotal}
The formattedTotal should be the total value calculated from the current filtered assets.

2. Optimized Computations — useMemo
Implement a single useMemo that returns:
{
  filteredAssets,
  totalValue
}
Filter the assets based on:
searchTerm — asset name matching should be case-insensitive.
selectedCategory — filter by assetClass.
If selectedCategory is "All", do not apply the category filter.
Calculate totalValue by summing:
quantity × currentPrice
for all filtered assets.
Inside the useMemo callback, include:
window.analyticsMemoCount = (window.analyticsMemoCount || 0) + 1;
The useMemo dependency array should contain only:
[assets, searchTerm, selectedCategory]
Changing currency should not trigger the useMemo.

3. Component Composition
FilterBar
Pass the following props to <FilterBar />:
searchTerm
setSearchTerm
selectedCategory
setSelectedCategory
currency
setCurrency
PortfolioMetrics
Pass the following props to <PortfolioMetrics />:
totalValue
currency
assetCount
Where:
assetCount = filteredAssets.length
AssetTable
Pass the following props to <AssetTable />:
assets = filteredAssets
currency = currency
